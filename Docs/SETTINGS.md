# Settings

## 1. Purpose

Define application-level settings that are not part of a specific project.

## 2. Categories

### General
- Startup behavior
- Recent projects
- Default project behavior

### Appearance
- Light / Dark / System
- UI preferences

### Editing
- Snapping
- Timeline preferences
- Default clip behavior

### Playback
- Preview quality
- Playback preferences

### Cache
- Cache location
- Cache limits
- Clear cache

### Modules
- Installed modules
- Enabled modules
- Module updates
- Module storage

### Shortcuts
- Keyboard shortcut customization

### Export
- Default export preferences

## 3. Project vs Application Settings

Application settings apply globally.

Project settings belong to the project and must travel with the project where appropriate.

## 4. Safety

Changing settings must not alter or delete source media unexpectedly.
