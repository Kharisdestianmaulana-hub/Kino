# Privacy

## 1. Principle

The application should minimize data collection and keep user media under the user's control.

## 2. Source Media

Source media remains in locations selected by the user.

The application must not upload source media without an explicit user action and a clearly communicated purpose.

## 3. Project Data

Project files remain under the user's control.

The application should not transmit project contents by default.

## 4. Optional Modules

Modules must follow the application's privacy rules.

A module must not silently upload user media, project information or personal data.

## 5. AI Modules

If AI functionality requires processing user media or text externally, the UI must clearly communicate:
- What data is sent
- Where it is processed
- Why it is required
- Whether the user can use an offline alternative

## 6. Diagnostics

Crash reports and diagnostic information should avoid unnecessary user content.

Any optional diagnostic sharing should be clearly communicated.

## 7. Third-Party Services

Integrations must require explicit user authorization.

Credentials and tokens must be stored using appropriate macOS security mechanisms.

## 8. Analytics

Analytics should be minimized and should not be required for basic editing functionality.

## 9. Privacy by Default

The default workflow should work without an account, cloud storage or mandatory telemetry where technically feasible.
