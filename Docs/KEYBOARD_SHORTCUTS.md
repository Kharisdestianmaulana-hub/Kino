# Keyboard Shortcuts

## 1. Principles

Shortcuts should follow familiar macOS and video-editing conventions where practical. Commands must also remain accessible through menus.

## 2. Project

| Action | Shortcut |
|---|---|
| New Project | ⌘N |
| Open Project | ⌘O |
| Save | ⌘S |
| Save As | ⇧⌘S |
| Close Project | ⌘W |

## 3. Editing

| Action | Shortcut |
|---|---|
| Undo | ⌘Z |
| Redo | ⇧⌘Z |
| Cut | ⌘X |
| Copy | ⌘C |
| Paste | ⌘V |
| Delete | Delete |
| Select All | ⌘A |
| Deselect | ⇧⌘A |
| Duplicate | ⌘D |

## 4. Timeline

| Action | Shortcut |
|---|---|
| Split | ⌘B |
| Enable / Disable Snapping | N |
| Add Marker | M |
| Zoom In | = |
| Zoom Out | - |
| Fit Timeline | ⇧Z |

## 5. Playback

| Action | Shortcut |
|---|---|
| Play / Pause | Space |
| Step Forward | → |
| Step Backward | ← |
| Go to Start | Home |
| Go to End | End |

## 6. Notes

Shortcut assignments are a starting baseline and may be revised after usability testing.

Conflicts with macOS system shortcuts must be avoided.

The application should eventually support customizable shortcuts.
