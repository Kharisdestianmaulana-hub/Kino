# Product Roadmap

## Modular Feature Strategy

The product defines 14 optional modules as part of the long-term feature roadmap. The existence of a module in this roadmap does not mean it must ship in v1.0.

### v1.0 Modules

| # | Module | Target |
|---|---|---|
| 1 | Effects | v1.0 |
| 2 | Transitions | v1.0 |
| 3 | Advanced Subtitles | v1.0 |
| 4 | Professional Color | v1.0 |
| 5 | Audio Pro | v1.0 |
| 6 | Advanced Export | v1.0 |

**v1.0 target: Core + 6 optional modules.**

Future modules remain part of the product plan even though they are not required for the v1.0 release.

## Development Strategy

The first release should validate the modular architecture with a manageable set of modules rather than attempting to complete all 14 at once.

Recommended implementation order:

1. Core architecture
2. Module Manager
3. Effects
4. Transitions
5. Advanced Subtitles
6. Professional Color
7. Audio Pro
8. Advanced Export
9. Future modules incrementally

A future module may be promoted into an active release when its technical maturity and product value justify it.
