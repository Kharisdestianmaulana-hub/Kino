# Design System

## 1. Design Philosophy
The interface should feel native to macOS while remaining distinctive as a professional creative application.

Principles:
- Content first
- Clear hierarchy
- Minimal visual noise
- Consistent spacing
- Predictable interaction
- Keyboard-friendly
- Accessible
- Dense where productivity requires it

## 2. Visual Direction
- Native macOS-inspired
- Professional
- Minimal
- Calm
- Functional
- Avoid unnecessary decoration

## 3. Layout
Primary workspace:
- Navigation / project area
- Media browser
- Viewer
- Inspector
- Timeline

The timeline is the primary editing workspace.

## 4. Typography
Use the native system font stack where possible.

Typography hierarchy:
- Window title
- Section title
- Body
- Secondary text
- Metadata
- Timeline labels
- Tooltips

## 5. Color
Use semantic colors rather than hard-coded colors:
- Background
- Surface
- Elevated surface
- Primary text
- Secondary text
- Separator
- Accent
- Destructive
- Warning
- Success

Support Light Mode and Dark Mode.

## 6. Components
Core components should include:
- Buttons
- Toolbars
- Segmented controls
- Sliders
- Toggles
- Menus
- Context menus
- Panels
- Sheets
- Dialogs
- Inspector controls
- Timeline controls
- Media items
- Tabs
- Progress indicators
- Empty states
- Error states

## 7. Interaction
- Prefer direct manipulation.
- Provide keyboard shortcuts for frequent operations.
- Preserve standard macOS conventions.
- Avoid destructive actions without confirmation when recovery is not possible.

## 8. Accessibility
- Support keyboard navigation.
- Maintain readable contrast.
- Provide accessible labels.
- Do not communicate state through color alone.
