# Contributing to Kino

Thank you for your interest in Kino! As per our licensing terms (PolyForm Shield), the source code is completely open for you to view, study, and learn from. 

## How You Can Contribute

Since this project has strict licensing regarding commercialization and distribution of modified copies, our contribution model works slightly differently from traditional Open Source projects:

1. **Bug Reports**: If you find a bug while running or studying the app, please open an Issue. Provide as much detail as possible, including macOS version and crash logs.
2. **Feature Requests**: We welcome ideas and suggestions for improving Kino. 
3. **Pull Requests (Bug Fixes Only)**: If you would like to submit a PR to fix a specific bug, you are welcome to do so. By submitting a PR, you agree to transfer the copyright of those specific changes to the repository maintainer.
4. **Learning & Discussion**: Feel free to use the Discussions tab to talk about the SwiftUI architecture, AVFoundation implementations, or anything else you've learned by reading the code.

## Rules
- Please ensure you have read and understood the `LICENSE` file.
- Do not submit PRs containing massive architectural changes or new monetization features without prior discussion.
- Maintain respectful communication in Issues and Discussions.

Thank you for exploring Kino!
